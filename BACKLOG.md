## Fonctionnalités à venir

### Validation du restaurant via API ouverte
Lorsque la dégustation a eu lieu dans un restaurant, proposer une validation de l'existence du restaurant en interrogeant une API publique (ex : Google Places, Foursquare, ou OpenStreetMap/Nominatim). Cela permettrait :
- d'auto-compléter le nom du restaurant à la saisie
- de normaliser le nom (éviter les doublons « Le Grand Véfour » / « grand vefour »)
- d'afficher une suggestion avec adresse pour confirmation avant enregistrement
